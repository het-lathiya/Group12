## Reading the evidence correctly

Downloaded logs are baseline evidence and are labelled with their run/commit. They were not rerun
locally. The current optional coverage run is separately linked in the unit report, and mutation
experiments report local commands/output separately. Existing [gate records](../progress/gates.md)
remain provisional: no deployment or release criterion is promoted by these documents.

A manual NFR run must record candidate SHA, environment, provider/scenario, tester, timestamp,
command, sample/workload and raw output. Percentiles require recorded observations and a stated
calculation; full-suite wall time is not request latency. A successful fake-provider run cannot
verify a real provider's availability, price, latency or rate limits.

Local `make check` and full E2E: **not run — operator fast mode; CI covers**.
Staging/live/load/device/security infrastructure work: **not run — pending staging window 1 Dec**.
